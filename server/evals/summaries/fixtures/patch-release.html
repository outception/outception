Version 2.4.1 fixes remote code execution flaw

The maintainers released version 2.4.1 on Monday to fix a remote code execution flaw in the template renderer that affects every release since 2.0. Users are advised to upgrade at once; there is no workaround short of disabling the renderer.

The flaw was reported privately three weeks ago and no exploitation in the wild has been seen, the maintainers said. The fix validates template names before they reach the loader.
